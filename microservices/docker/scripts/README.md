# Docker Scripts Directory

This directory is reserved for deployment and startup scripts for local development and AWS EC2 deployment via Docker Compose.

## Planned Scripts

- `start-dev.sh` / `start-dev.bat`: Helper scripts to launch Docker Compose services in development mode.
- `stop-dev.sh` / `stop-dev.bat`: Helper scripts to tear down local containers and clean networks.
- `deploy-ec2.sh`: Shell script for automated deployment on AWS EC2 instances.
