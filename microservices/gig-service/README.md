# Gig Service (`gig-service`)

## Overview
Microservice responsible for service gig creation, categories, search/filtering, pricing packages, and Cloudinary media upload management.

## Stack
- Java 21
- Spring Boot 3.3.5
- Eureka Client
- Cloudinary Integration (Future Migration Phase)

## Port
- `8083`
