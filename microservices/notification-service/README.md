# Notification Service (`notification-service`)

## Overview
Microservice implemented in C# / .NET 8 Web API responsible for transactional email, SMS, and real-time push notifications across the marketplace.

## Stack
- C# / .NET 8.0 Web API
- ASP.NET Core Minimal APIs / Web API
- Swagger / OpenAPI

## Port
- `8087`

## Future Database
- `freelance_notification_db`

## Key Responsibilities
- Sending email alerts (Order updates, Payment receipts, Account verification).
- Real-time SignalR notifications for chat/messages and order status updates.
